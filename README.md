### 🏗️ Projetos em Destaque

#### 🛒 [ecommerce-lakehouse](https://github.com/cardosogg/ecommerce-lakehouse)
Pipeline de Engenharia de Dados local construído sobre a **Arquitetura Medallion** (Bronze, Silver, Gold).
* **Stack:** Python, dbt, DuckDB, PyArrow
* **Destaques:** Processamento analítico moderno com transformações em camadas e armazenamento otimizado.

#### 🐾 [doghouse-lakehouse](https://github.com/cardosogg/doghouse-lakehouse)
Modelagem e estruturação analítica de banco de dados para gestão operacional e relatórios estratégicos.
* **Stack:** Python, SQL, DuckDB, Pandas
* **Destaques:** Ingestão de dados não estruturados/semi-estruturados convertidos para esquemas analíticos prontos para BI.

#### ⚡ [pokemon-analytics](https://github.com/cardosogg/pokemon-analytics)
Pipeline ETL automatizado de ponta a ponta com orquestração agendada.
* **Stack:** Apache Airflow, Docker, PostgreSQL, Streamlit, PokéAPI
* **Destaques:** Infraestrutura containerizada rodando DAGs operacionais com visualização em dashboard interativo.

#### 🕺 [breaking-data-project](https://github.com/cardosogg/breaking-data-project)
Análise exploratória e estruturação de dados aplicados a métricas e eventos esportivos de Breaking.
* **Stack:** Python, Pandas, Matplotlib
* **Destaques:** Tratamento de dados não padronizados e geração de visualizações de valor.
